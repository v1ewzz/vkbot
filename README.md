# VKBot — Каталог личной библиотеки во ВКонтакте

Бот для сообщества ВКонтакте, который позволяет вести каталог личной библиотеки и читать книги прямо в переписке. Написан на Python с использованием Flask и VK Callback API.

## Возможности

- Добавление книг через интерактивный диалог: автор, название, жанр, год издания
- Загрузка текста книги в виде `.txt` файла
- Чтение книги прямо в переписке — текст разбивается на порции по 1000 символов, листать можно кнопками в сообщении
- Статусы чтения: «хочу прочитать», «читаю», «прочитано»
- Прогресс чтения сохраняется для каждой книги
- Главное меню с кнопками и inline-кнопки в сообщениях

## Команды

| Команда | Описание |
|---|---|
| `/start` или «помощь» | Приветствие и главное меню |
| `/add` или «добавить книгу» | Добавление книги через диалог |
| `/list` или «мой каталог» | Показать каталог книг |
| `/read <ID>` | Начать чтение книги |
| `/status <ID> <статус>` | Изменить статус книги |

## Технологии

- Python 3.13
- Flask — веб-сервер и обработка Callback API
- vk-api — работа с VK API
- SQLite — хранение пользователей, книг и статусов
- Docker — контейнеризация
- ngrok — локальный туннель для разработки

## Структура проекта

```
├── bot.py              # основной код бота (Flask-приложение)
├── books/              # загруженные тексты книг (файлы .txt)
├── library.db          # база данных SQLite (создаётся автоматически)
├── requirements.txt    # зависимости Python
├── Dockerfile          # образ для Docker
├── run_ngrok.ps1       # скрипт запуска ngrok для локальной разработки
└── .env.example        # пример переменных окружения
```

## Установка и запуск

### 1. Настройка сообщества VK

1. Создайте сообщество ВКонтакте
2. В разделе «Управление» → «Дополнительно» → «Работа с API» создайте ключ доступа
3. Настройте Callback API:
   - в типах событий поставьте галочки на `Входящее сообщение`, `Исходящее сообщение`, `Разрешение на получение` и `Действие с сообщением`
   - укажите адрес сервера (URL вашего бота). В случае, если у вас его нет — это обсуждается на 3 шаге.
   - скопируйте строку подтверждения

### 2. Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения:

| Переменная | Описание |
|---|---|
| `VK_TOKEN` | Ключ доступа сообщества (Работа с API) |
| `CONFIRM_STRING` | Строка подтверждения из Callback API |
| `VK_SECRET` | Секретный ключ Callback API (опционально). Если задан — сервер проверяет подпись `X-Vk-Signature` каждого события |

### 3. Запуск

**Локально:**

```bash
pip install -r requirements.txt
python bot.py
```

Для приёма запросов от VK нужен публичный HTTPS-адрес. С локальной машины проще всего использовать ngrok:

```powershell
.\run_ngrok.ps1
```

Скрипт запускает туннель на порт 5000 — полученную ссылку вставьте в настройки Callback API.

**Через Docker:**

```bash
docker build -t vkbot .
docker run -p 5000:5000 -e VK_TOKEN=... -e CONFIRM_STRING=... -e VK_SECRET=... vkbot
```

Сервер запускается на порту 5000, при открытии в браузере вернёт статус «Бот работает!».
